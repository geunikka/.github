# 😎 그니까 

## 프로젝트 Remindy

### 개요
> 💡 **부주의하거나 집중이 어려운 이들이, 일정 및 할 일을 빠르게 메모하면  
> AI가 자동으로 기록하고 적절한 타이밍에 (아이폰) 알림으로 알려주는 앱, REMINDY**  

일상 속에는 일정으로 남기기엔 애매하지만 잊어버리기 쉬운 일들이 많습니다.  
생필품을 사는 일, 외출 전에 준비물을 챙기는 일처럼요.  
REMINDY는 그런 사소한 생각들을 놓치지 않도록 돕기 위해 만들어졌습니다.  

간단히 메모만 남기면, AI가 기억해야 할 시점을 판단해 조용히 알려줍니다.  
시간이 지날수록 REMINDY는 사용자의 생활 패턴을 이해하고, 더 자연스러운 타이밍에 개입합니다.  
할 일도, 기억해야 할 것도 많은 우리, 사소한 일들은 REMINDY에게 맡겨 봐요.  

### 핵심 기능
| 기능 | 설명 |
| --- | --- |
| 메모 입력 | 음성 / 텍스트로 빠르게 메모 (잠금 화면 / 위젯) |
| AI 정리 | 메모 내용을 AI가 분석해서 1. 카테고리 태깅 / 2. 할 일로 변환  |
| 리마인더 설정 | 사용자가 원하는 시간 / AI가 적절히 추측해서 알림 설정 |
| 알림 설정 | (아이폰) 잠금 화면에서 상시 표시 / 푸시 알림 / 미루기 기능 |
| 알림 시간 추정 | 초기 설문 기반으로 적절한 알림 시점 추정 |

### 타겟
| 특징 | 부주의함, 잘 잊음, 일정 관리에 익숙하지 않음 |
| --- | --- |
| 상황 | 바쁜 일상, 생각은 많은데 정리가 어려움 |
| 범주 | 학생, 직장인, ADHD 성향 |
